# Canvas Card Shapes（卡片形状）

给白板卡片套形状 —— 基础几何 + **编程逻辑示意图**的标准符号。Obsidian 原生卡片只有矩形一种。

- 右键卡片 →「卡片形状」→ 选一个（当前生效的那项打勾）
- **框选多张再右键** → 一次给它们套同一个形状
- 命令面板 →「卡片形状：菱形」等，作用于选中的卡片

## 形状清单

| 组 | 形状 |
|---|---|
| **基础几何**（12） | 直角矩形 · 圆角矩形 · 胶囊 · 椭圆 · 菱形 · 平行四边形 · 六边形 · 八边形 · 三角形 · 星形 · 云形 · 折角便签 |
| **流程图**（12） | 起止符 · 处理 · 判断/分支 · 输入输出 · 预定义处理 · 文档 · 数据库 · 手动输入 · 延时/等待 · 注释 · 准备 · 连接点 |

流程图那一组是编程逻辑示意图（流程图）的通用符号：判断用菱形、输入输出用平行四边形、
数据存储用圆柱体、起止用胶囊 —— 画算法流程时不用再自己拼形状。

## 两条实现上的取舍（先说清楚）

1. **圆角类形状保留描边，裁剪类形状没有描边。**
   圆角 / 胶囊 / 椭圆 / 云形 / 文档 / 数据库 / 延时 这几类是 `border-radius` 做的，
   卡片原生描边跟着圆角走，好看。菱形 / 六边形 / 平行四边形 / 三角形 / 星形 /
   折角便签 这几类是 `clip-path` 裁出来的，而 **CSS 的裁剪只能裁形状、不能描边** ——
   要描边就得叠两层元素，那会破坏 Obsidian 的选中框和拖动，不值得。
   裁剪类形状改用 `filter: drop-shadow()` 给一圈顺着形状走的阴影轮廓，
   选中时换成主题强调色的光晕（原生那条矩形选中圈会被裁掉，等于没有）。
   ⚠️ 这里有个坑：CSS 规范里 `filter` 是**先于** `clip-path` 应用的，两个写在同一个
   元素上阴影会被一起裁掉 —— 所以阴影挂在卡片框上、裁剪挂在它里面那一层。

2. **正文是垂直居中的。**
   Obsidian 原生把正文贴着卡片上边放；菱形、三角形、星形这类"上窄下宽"的形状，
   文字就正好落在最窄的地方被裁掉一半。根因是核心样式里正文块会**吃掉全部剩余高度**
   （上面只留一个 16px 的占位块）。插件把"谁分剩余高度"反过来：正文块不再抢高度，
   上下两个占位块均分，正文就落在形状正中。
   字多到装不下时会自动退回贴顶排版，**不会裁掉开头**。

3. **形状记在插件自己的数据文件里，不写进 `.canvas`。**
   白板文件始终是标准 JSON Canvas 格式，别的工具、别的电脑打开都不会看到私有字段。
   代价：卸载插件后形状会丢失 —— 这和配套的 *Canvas Node Align* 是同一个取舍。

## 设置

- **内边距** —— 文字离卡片边缘的留白。菱形、三角形这类形状可用面积小，本来就额外留得多；
  字多的时候把卡片拉大一点更实在。

## 已知限制

- 形状**不改变卡片大小**，也不改变连接线的落点。连线仍然锚在卡片的矩形包围盒上，
  所以菱形卡片的线看起来会连到"角"附近 —— 这是 Obsidian 画布本身的机制。
- 文字在裁剪类形状里是**矩形排布再被裁**，不是贴着形状排。极端情况下（卡片很扁、
  文字很长）可能被裁掉一点，这时把卡片拉大或减少文字。
- 图片卡、嵌入卡都能套形状，但图片被裁的形状看起来可能不是你要的效果。
  **分组框（Group）不会生效** —— 它是装别的卡片的容器，裁成形状会把里面的
  卡片一起藏掉，所以插件刻意排除了它。

## 和其它插件的关系

- **Canvas Node Align** —— 卡片/标签的文字对齐（水平 + 垂直），和本插件配套使用。
- 社区里 *Advanced Canvas* 也提供一套流程图形状的节点样式；本插件额外汇集了
  装饰性形状（星形 / 云形 / 折角便签 / 八边形等）、中文菜单，以及"和文字对齐共存"的
  内边距处理。你可以按需要选一个用，两者不冲突。

## 安装

社区插件里搜 **Canvas Card Shapes**（等目录审核通过后），或把 `main.js`、`manifest.json`、
`styles.css` 放进 `<你的库>/.obsidian/plugins/canvas-card-shapes/`，再到「设置 → 第三方插件」启用。

## 开发

```
main.js          形状表 + 菜单 + 命令 + 重挂机制（ES2017，无打包器、无依赖）
styles.css       公共规则（内边距 / 垂直居中 / 圆角族与裁剪族的补偿）+ 每个形状的变量
                 形状只声明变量，视觉属性全部由公共规则消费：
                 圆角族走 --shapes-radius，裁剪族走 --shapes-clip
test/shapes.test.js  433 条断言：形状表契约、数据键、挂/读类名、样式表双向守卫、接线守卫
test/build.test.mjs  测发布工具链本身
```

```bash
npm test          # 两个测试文件
npm run build     # 和社区目录跑的同一条命令
npm run verify    # 清单 + 构建 + 测试
```
